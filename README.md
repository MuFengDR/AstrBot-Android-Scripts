# AstrBot Android Scripts

这是 AstrBot Android 客户端使用的 Linux 环境安装脚本仓库，提供基础命令、uv、NapCat 和 AstrBot 等环境组件的安装与维护脚本。

脚本由 AstrBot Android 客户端按版本获取和校验。普通用户无需手动操作本仓库；如果应用内更新失败，可以从 [Releases](https://github.com/MuFengDR/AstrBot-Android-Scripts/releases) 下载离线安装包，并在应用内使用“导入脚本”功能安装。

## 版本内容

每个 Release 包含在线更新所需的版本信息，以及供离线导入使用的安装包。请使用与应用提示相符的版本，不要混用不同版本的文件。
